## 📋 Контекст

Запросы написаны для схемы базы данных бронирования авиабилетов. Основные таблицы:

| Таблица | Назначение | Ключевые поля |
|:---|:---|:---|
| `bookings` | Бронирования | `book_ref`, `book_date`, `total_amount` |
| `tickets` | Билеты | `ticket_no`, `book_ref`, `passenger_id`, `passenger_name` |
| `ticket_flights` | Связь билетов и рейсов | `ticket_no`, `flight_id`, `fare_conditions`, `amount` |
| `flights` | Рейсы | `flight_id`, `flight_no`, `status` |
| `boarding_passes` | Посадочные талоны | `ticket_no`, `flight_id`, `boarding_no`, `seat_no` |

## 🎯 Навыки

- Фильтрация и сортировка данных (`WHERE`, `ORDER BY`)
- Работа с датами и интервалами (`now()`, `interval`)
- Проверка на `NULL` и граничные значения
- Агрегация и группировка (`COUNT`, `GROUP BY`, `HAVING`)
- Множественные `JOIN` (INNER, LEFT)
- Составные условия в `JOIN` (по двум полям)
- Проверка консистентности данных: orphaned rows, missing records

## 📌 Как использовать

1. Скачайте и разверните БД https://edu.postgrespro.ru/demo-big.zip
2. Подключитесь к БД `demo` (PostgreSQL) или любой БД с аналогичной схемой.
3. Откройте нужный `.sql`-файл — внутри каждого запроса есть контекст и комментарии.
4. Выполните запрос в вашем SQL-клиенте (DBeaver, pgAdmin).
5. Для запросов-проверок (проверка NULL, поиск осиротевших записей, поиск пассажиров без талонов): пустой результат означает, что данные консистентны — это ожидаемое поведение.
